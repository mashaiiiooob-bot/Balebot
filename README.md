# Balebot — Telegram → Bale news relay (GitHub Actions)

بدون نیاز به روشن بودن گوشی. GitHub Actions هر ۵ دقیقه یک اجرا شروع می‌کند و هر اجرا حدود ۵ دقیقه زنده می‌ماند و هر ۱۵ ثانیه کانال‌ها را بررسی می‌کند؛ اجراها با `concurrency` پشت‌سرهم صف می‌شوند، پس تأخیر معمول چند ده ثانیه است. زمان‌بندی GitHub تضمین‌شده نیست و گاهی اجرا با تأخیر شروع می‌شود، اما پیام‌ها از طریق checkpoint هرگز جا نمی‌مانند.

## راه‌اندازی

### ۱) ساخت TG_SESSION (یک بار، روی گوشی یا کامپیوتر خودت)
```
pip install telethon
python generate_session.py
```
API ID و API HASH را از my.telegram.org بگیر. خروجی را فقط در Secrets بگذار. **از همین session جای دیگری هم‌زمان استفاده نکن** (تلگرام ممکن است آن را باطل کند). حساب تلگرام باید عضو همه‌ی کانال‌های منبع باشد.

### ۲) افزودن Secrets
مخزن → Settings → Secrets and variables → Actions → **Secrets**:

| نام | مقدار |
|---|---|
| `TG_API_ID` | API ID |
| `TG_API_HASH` | API HASH |
| `TG_SESSION` | خروجی مرحله ۱ |
| `BALE_BOT_TOKEN` | توکن ربات بله |
| `SOURCES` | هر منبع در یک خط (لینک/یوزرنیم/شناسه عددی) |

لاگ‌های مخزن عمومی برای همه دیده می‌شوند؛ برنامه لینک منبع‌ها و متن پیام‌ها را چاپ نمی‌کند.

### ۳) (اختیاری) Variables
`BALE_DESTINATION` (پیش‌فرض `@maklpo`)، `SIGNATURE`، `LOOP_SECONDS` (پیش‌فرض ۳۰۰)، `POLL_INTERVAL` (پیش‌فرض ۱۵)، `BACKFILL_LIMIT` (پیش‌فرض ۰: اولین اجرا فقط از اکنون شروع می‌کند).

### ۴) اجرا
تب Actions → Balebot poll → Run workflow برای تست. بعد از آن خودکار اجرا می‌شود.

## نکات
- وضعیت (آخرین شناسه‌ی هر کانال، با کلید هش‌شده) در شاخه‌ی `state` ذخیره می‌شود.
- اگر ارسال یک پیام شکست بخورد، دور بعد دوباره تلاش می‌شود؛ پس از ۵ شکست رد می‌شود.
- در مخزن **عمومی** دقیقه‌ی Actions رایگان و نامحدود است. در مخزن خصوصی این الگو سهمیه‌ی ماهانه را می‌سوزاند؛ `LOOP_SECONDS` را کم کن (مثلاً ۳۰) تا هزینه کم شود، به قیمت تأخیر بیشتر.
- اگر مخزن مدتی طولانی بدون فعالیت بماند، GitHub زمان‌بندی را غیرفعال می‌کند؛ در Actions دوباره فعالش کن.
- فیلتر خبر کلیدواژه‌ای است، پیام بدون متن (مثلاً عکس بدون کپشن) رد می‌شود، آلبوم‌ها جداگانه ارسال می‌شوند و فایل بزرگ‌تر از ۴۵MB فقط به‌صورت متن می‌رود.
- مسئولیت رعایت حق نشر و قوانین کانال‌ها با مدیر پروژه است.
