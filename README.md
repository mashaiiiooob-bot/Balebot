# Balebot — Telegram to Bale news relay

این پروژه برای اجرا روی گوشی اندرویدی با Pydroid 3 آماده شده است. GitHub فقط برای نگهداری کد است؛ برنامه روی گوشی اجرا می‌شود.

## امکانات نسخه فعلی
- پایش رویدادمحور کانال‌های تلگرام با Telethon
- ارسال متن و رسانه‌های تکی به Bale
- امضای ثابت `⚔️ @Bale_Dr`
- ثبت پیام‌های پردازش‌شده در SQLite برای جلوگیری از ارسال تکراری
- تلاش برای بازیابی پیام‌های جاافتاده پس از خاموشی، با ذخیره آخرین شناسه هر کانال
- فیلتر اولیه واژه‌محور چندزبانه؛ این فیلتر هوش مصنوعی نیست و ممکن است خبر را از دست بدهد یا مورد غیرخبری را عبور دهد.

## نصب
1. فایل ZIP را استخراج کن.
2. در Pydroid 3 ترمینال را باز کن و وارد پوشه پروژه شو.
3. اجرا کن:
   `pip install -r requirements.txt`
4. از `config.example.py` یک کپی با نام `config.py` بساز و مقادیر را در آن وارد کن.
5. اجرا:
   `python main.py`

## تنظیمات تلگرام
از `my.telegram.org` مقدارهای API ID و API HASH حساب خودت را بگیر. در اجرای اول، Telethon شماره تلفن و کد ورود را در ترمینال می‌خواهد. فایل نشست `.session` محرمانه است؛ آن را در GitHub قرار نده.

کانال خصوصی را با لینک دعوت به‌تنهایی نمی‌توان در همه حالت‌ها به‌عنوان منبع پایدار تنظیم کرد. برنامه تلاش می‌کند لینک را resolve کند؛ اگر resolve نشد، شناسه عددی کانال را در `SOURCES` قرار بده. فقط کانال‌هایی را اضافه کن که اجازه دسترسی و بازنشر محتوای آن‌ها را داری.

## تنظیمات Bale
توکن ربات را فقط در `config.py` محلی قرار بده. توکن قبلی که در گفت‌وگو ارسال شده بود را باطل و تعویض کن. توکن واقعی، API HASH و فایل session را در مخزن عمومی منتشر نکن.

## نکات و محدودیت‌ها
- مقصد آزمایشی به‌صورت پیش‌فرض `@maklpo` است.
- آلبوم‌ها در این نسخه به‌صورت پیام‌های جداگانه ارسال می‌شوند.
- تشخیص خبر با فهرست کلیدواژه انجام می‌شود، نه تحلیل معنایی واقعی.
- تشخیص تکرار بین دو کانال مختلف بر اساس شباهت متن/تصویر هنوز در این نسخه وجود ندارد؛ جلوگیری از تکرار بر اساس شناسه پیام منبع انجام می‌شود.
- برای کارکرد مداوم، Pydroid باید فعال بماند و اندروید نباید اجرای پس‌زمینه آن را متوقف کند. اجرای ۲۴ساعته تضمین‌شده نیست.
- مسئولیت رعایت حق نشر، قوانین کانال‌ها و ذکر منبع با مدیر پروژه است.
